## The current product

MusicCloud is built around a simple loop: **connect a wallet → publish → get a fair turn → build an audience → keep the ownership trail.**

- **$1 registration** — connect a wallet and sign the ownership challenge.
- **$10 lifetime Pro** — a separate one-time upgrade for the expanded creator toolkit.
- **Fair discovery** — rotation considers time since last feature instead of treating follower count as destiny.
- **Creator ownership** — editions and resale activity are designed around visible artist-facing economics on Base L2.
- **Native provenance** — the MusicCloud chain records public work, revisions, transfers, hashes, proofs, and chain-derived rewards.

## What people can do

| Surface | MusicCloud today |
|---|---|
| **Discover** | Fair rotation, weighted trending, search, genres, and a two-track-per-artist chart cap |
| **Listen** | Persistent player, real waveform seeking, visualizer, timestamp comments, playlists, and queue control |
| **Publish** | Tracks, photos, videos, status updates, voice memos, and creator-owned editions |
| **Connect** | Follows, reposts, threaded comments, DMs, realtime notifications, and live Spaces |
| **Collect** | ERC-1155 editions on Base L2, profile collections, ownership history, and resale provenance |
| **Verify** | MusicCloud blocks, SHA-256 commitments, Merkle proofs, media manifests, and validator checkpoints |

## How the chain fits

1. **Identity** — a wallet signature establishes the publishing account.
2. **Public record** — eligible work and native transfers enter the MusicCloud protocol.
3. **Settlement** — edit windows, content commitments, and revision history become readable.
4. **Proof** — blocks, hashes, Merkle paths, and checkpoints let people verify the trail.
5. **Value** — Music Clouds are derived from chain-block work and distributed to contributing authors.
